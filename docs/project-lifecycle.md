# 專案封存、垃圾桶與復原（R09）

適用本機單程序個人版。封存／垃圾桶與業務狀態「維護中、已結案、移交中」獨立；不把「已結案」當刪除，也不自動清空資料。

## 日常操作

首頁提供使用中（預設）、已封存、垃圾桶三個分類。分類徽章為該分類的全部數量；搜尋／狀態篩選及結果數只作用於目前分類，卡片／清單、10／20／50 分頁及重設保留分類。封存／垃圾桶不覆寫原有首頁偏好，也不會被記住的使用中篩選自動帶走。

在專案內容右上角按「管理專案」。垃圾桶的卡片／清單只連到管理頁，不載入專案正文或帳號資料。管理頁顯示專案名稱、分類及五類內容數量，不查詢或回傳密碼、密文或 nonce。

| 操作 | 起點 | 結果與資料處理 |
| --- | --- | --- |
| 封存 | 使用中 | 移至已封存；保留所有內容，仍可查看、編輯及匯出。不是唯讀鎖或權限功能。 |
| 取消封存 | 已封存 | 回到使用中，維持業務狀態與內容。 |
| 移至垃圾桶 | 使用中／已封存 | 保留專案 ID、五類關聯資料、密文及原封存標記；阻擋內容讀取、編輯、普通／敏感匯出與密碼讀取。撤銷全部保管庫解鎖 session。 |
| 復原 | 垃圾桶 | 只清除垃圾桶標記，回到原本的使用中／已封存分類。需要密碼時重新以原主密碼解鎖。 |
| 永久刪除 | 垃圾桶 | 先成功建立並驗證完整 SQLite 復原點，再透過外鍵 CASCADE 刪除專案及五類子資料。不刪其他專案、全域保管庫設定或敏感匯出政策；再次撤銷全部解鎖 session。 |

每項操作需展開確認區，輸入**完整且完全相同**的專案名稱並勾選確認。所有變更均為受來源／CSRF／單次送出保護的 POST；GET 不變更資料，未啟用 JavaScript 也可使用。失敗時回到管理頁、顯示雙語原因，名稱及勾選需重新確認。每次內容／基本資料／生命週期變更遞增 `revision`；舊分頁即使在同一秒送出，或經封存／取消封存來回，也不能沿用舊確認。

垃圾桶不只是首頁隱藏：舊網址、舊編輯表單、備註局部載入、內容操作及解密 API 均重新檢查父專案。子資料寫入與父專案檢查在同一交易，失敗整筆回滾。資料已下載、複製或原先顯示在畫面上的資訊無法收回；此功能不是使用者認證或多人存取控制。

## 永久刪除與復原點

預設存放於：

```text
data/backups/projmemo-pre-delete-YYYYMMDD-HHMMSS-microseconds.sqlite3
```

自訂 `PROJMEMO_DB_PATH` 時，存放在該資料庫旁的 `backups/`。使用獨占檔名建立，不覆寫同名檔。確認資料、保留 SQLite 寫入權、建立並驗證快照、刪除在同一個 `BEGIN IMMEDIATE` 交易範圍內完成；快照使用另一個唯讀連線取得刪除前的已提交資料，包括 WAL。未建立／驗證快照就不刪除；刪除或提交失敗會回滾，已完成的復原點仍保留。

資料備份頁將還原前與永久刪除前快照合併列出最近 10 份、分別標示來源；檔案**不自動刪除**。可下載後按既有備份流程還原。完整備份也包含封存／垃圾桶標記；從刪除前快照還原後，專案先回到垃圾桶，再到管理頁按「復原專案」。

注意事項：

- 復原點包含**整個資料庫**，不是單一專案匯出；還原會取代所有專案與設定，勿用舊快照覆蓋尚未另存的新資料。需要合併單一專案並非本項功能。
- Web 上傳仍受原有 100 MB 限制；較大快照需停止服務後依離線復原程序驗證及處理，不能用提高限制或覆寫唯一副本冒險還原。
- 密碼仍為原始密文，主密碼不在備份內。原 salt／KDF／加密 AAD 不改，仍使用原主密碼。
- **不是安全抹除**：SQLite 未使用空間、WAL、舊備份及本次復原點仍可能保留資料。本功能不執行 VACUUM、不清除復原點，也不承諾密碼無法恢復。
- 同磁碟復原點不能取代獨立備份；硬體故障、斷電、強制終止仍依 [備份復原指南](backup-recovery.md) 處理。維持單程序／單 worker，外部 SQLite 工具不得同時寫入。

## Schema 與驗證

v4 追加 `projects.archived_at`、`deleted_at`（空字串表示未標記）、`revision`（非負整數）及 `idx_projects_lifecycle`。不修改已發布的 v1–v3 migration；升級沿用前快照、原子交易、失敗復原及重啟不重複套用。支援 v0–v3 舊備份，拒絕版本／生命週期欄位不符、錯誤時間／revision 或索引結構。

回歸包含全部 16 種內容變更在垃圾桶中回滾、過期確認與並行送出、普通／敏感匯出及 reveal 阻擋、DELETE／WAL 快照、備份／驗證／提交失敗、五類 CASCADE 與不相關資料保留、加密帳號復原、雙語原生表單／重送、分類篩選分頁、v3 升級／失敗回復及無 JavaScript 瀏覽器操作。測試只用暫存假資料，不能指向正式 DB。

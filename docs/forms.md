# 表單、草稿與驗證

本機個人版；一般資料與帳號 metadata 不是加密欄位。請只將實際密碼填入指定密碼欄位。

## 伺服器端輸入規則（R05）

所有新增／編輯共用 `app/validation.py`，即使關閉 JavaScript 或直接送出 POST 也適用。錯誤時不寫入；既有資料不在讀取、升級或匯出時自動截斷／改寫。

| 欄位 | 字元上限 |
| --- | ---: |
| 專案名稱、內容標題、帳號／服務名稱 | 200 |
| 描述、備註、權限、用途、Secret 參照 | 10,000 |
| Markdown 本文 | 100,000 |
| URL、主機／登入位置 | 4,096 |
| 環境變數名稱、資料庫名稱 | 256 |
| 負責人、標籤、登入名稱、環境設定來源／負責人 | 1,000 |
| 帳號密碼 | 4,096 |
| 主密碼 | 設定時至少 16，設定／解鎖皆最多 1,024 |

一般文字去除兩端空白、拒絕 NUL；密碼維持原字元與空白，不正規化。負責人／標籤接受中英文逗號、頓號、分號與換行，移除空項、大小寫不敏感去重但保留第一筆原字型，以 `, ` 保存。畫面 token 編輯仍可用。

列舉不再將未知值默默改成預設值，而是回報欄位錯誤。URL 需有合法 HTTP／HTTPS scheme、主機及有效 port；支援 localhost、IPv4／IPv6、IDNA 主機，拒絕空主機、空白、反斜線與內嵌帳密。只驗證結構、不連線測試或擷取網址。帳號 endpoint 可以是 `host:port`／SSH 主機，不強迫使用 HTTP URL。

原生 HTML 表單失敗會在原操作頁展開對應表單並顯示雙語摘要／欄位錯誤；一般輸入經 HTML 跳脫回填，密碼與上傳檔案須重填。JSON 用戶端保留簡短 detail，不輸出驗證 input／ctx，不把密碼寫入草稿或錯誤訊息。CSRF／來源保護照常適用。

## 送出與重試

專案與五類內容表單使用 PRG、成功提示、原區段 anchor，並保留卡片／明細偏好。表單簽署 `_submission_token` 綁定目前瀏覽器的 CSRF；重送相同成功 token 只取得同一 redirect，不再次新增、編輯或翻轉完成狀態。驗證／DB 回滾錯誤可修正後重試；仍在執行或結果不明時先等候／檢查，不自動重新建立。

單程序記憶體只保留 token、到期時間、path、狀態和安全 Location，不記錄輸入、密碼或其 hash。24 小時到期、程序重啟、簽章錯誤會拒絕，請先確認資料再刷新；10,000 筆滿時拒絕新送出，不淘汰未過期完成紀錄。不承諾多 worker／跨重啟 exactly-once。JavaScript 的停用按鈕只是輔助，關閉 JS 仍有伺服器 token 保護；JSON 腳本可選擇攜帶 token，未攜帶仍維持原行為。

## 離開與草稿

啟用 JavaScript 時，切語言或離開有修改的頁面需確認；取消時保留 DOM 原輸入，確認才離開，不把草稿或密碼寫進 localStorage／sessionStorage。舊版專案 metadata 語言草稿不再讀寫。重新整理、關閉頁面及瀏覽器歷史離開使用瀏覽器原生提示（措辭與顯示由瀏覽器決定，需有使用者互動）；無 JS 時不承諾離開保護。pagehide 會清空密碼，bfcache 返回不恢復密碼。

儲存目前表單僅排除該表單，其他草稿仍需確認；切卡片／明細或同頁 anchor 不丟 DOM。下載匯出、新分頁不視為離開。原生表單錯誤回填後仍視為未保存草稿，切語言會回對應 GET 頁，不導向 POST 位址；密碼到期仍依保管庫原政策清空，普通草稿保留。

# 表單、草稿與驗證

本機個人版；一般資料與帳號 metadata 不是加密欄位。請只將實際密碼填入指定密碼欄位。

## 伺服器端輸入規則（R05）

所有新增／編輯共用 `app/validation.py`，即使關閉 JavaScript 或直接送出 POST 也適用。錯誤時不寫入；既有資料不在讀取、升級或匯出時自動截斷／改寫。

| 欄位 | 字元上限 |
| --- | ---: |
| 專案名稱、內容標題、帳號／服務名稱 | 200 |
| 描述、備註、權限、用途、Secret 參照 | 10,000 |
| Markdown 本文 | 100,000 |
| URL、主機／登入位置 | 4,096 |
| 環境變數名稱、資料庫名稱 | 256 |
| 負責人、標籤、登入名稱、環境設定來源／負責人 | 1,000 |
| 帳號密碼 | 4,096 |
| 主密碼 | 設定時至少 16，設定／解鎖皆最多 1,024 |

一般文字去除兩端空白、拒絕 NUL；密碼維持原字元與空白，不正規化。負責人／標籤接受中英文逗號、頓號、分號與換行，移除空項、大小寫不敏感去重但保留第一筆原字型，以 `, ` 保存。畫面 token 編輯仍可用。

列舉不再將未知值默默改成預設值，而是回報欄位錯誤。URL 需有合法 HTTP／HTTPS scheme、主機及有效 port；支援 localhost、IPv4／IPv6、IDNA 主機，拒絕空主機、空白、反斜線與內嵌帳密。只驗證結構、不連線測試或擷取網址。帳號 endpoint 可以是 `host:port`／SSH 主機，不強迫使用 HTTP URL。

原生 HTML 表單失敗會在原操作頁展開對應表單並顯示雙語摘要／欄位錯誤；一般輸入經 HTML 跳脫回填，密碼與上傳檔案須重填。JSON 用戶端保留簡短 detail，不輸出驗證 input／ctx，不把密碼寫入草稿或錯誤訊息。CSRF／來源保護照常適用。
